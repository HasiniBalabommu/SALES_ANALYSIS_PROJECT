📊 Sales Data Analysis Project
📌 Overview

This project analyzes retail sales data to identify:

Revenue trends
Top-performing products
Regional performance
Profitability insights

🛠️ Tools Used
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook


📂 Dataset
Superstore Sales Dataset
Contains order, product, customer, and profit information


📈 Key Analyses
Monthly Revenue Trends
Product Performance
Region-wise Sales
Profit Analysis



🔍 Key Insights
Revenue peaks during Q4
Certain high-selling products generate low profit
Some regions consistently underperform


🚀 Future Improvements
Interactive dashboard using Streamlit
Real-time data updates
